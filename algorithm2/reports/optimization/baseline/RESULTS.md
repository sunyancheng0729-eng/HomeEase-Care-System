# HomeEase 四动作算法 2 实验结果

本文件由 `scripts/build_report.py` 从实际实验 JSON 生成，开发方法和限制见 [DEVELOPMENT.md](DEVELOPMENT.md)，系统接口见 [API.md](API.md)。

## 默认模型与结论

默认时序模型：**gru_b2_w64**。成员：`gru_b2_w64.pt`。Decoder 为 `ordered_posterior`，阶段证据阈值 0.25，消抖时长 0.1 秒。默认姿态前端：**yolo11n-pose.pt @ 640**。

测试动作 Macro-F1 **0.8213**，联合动作／阶段 Macro-F1 **0.7007**。测试重建会话 MAE **1.80 次**，非零参考会话 MAPE **23.47%**，相对计数 accuracy **76.53%**。

时序模型 CPU P50 **10.268 ms**，P95 **15.013 ms**，参数量 **55,185**。这些是 64 帧窗口的单次前向耗时，不包含 Pose CNN。

选择仅依据验证集：计数 MAE 与最优相差不超过 0.25 次、阶段 F1 与符合条件的最好模型相差不超过 0.02，再选 CPU P50 最小者。公开骨架投影、弱标签和重建回放结果不等于老人家庭视频性能。

## 是否达到 proposal 的目标

当前默认模型重建回放总体 MAPE 为 23.47%。未达到 ≤5% 的目标，不能把实现完成写成精度目标已经完成。

代码、训练权重、四动作识别与计数流程、接口和离线实验已实现。下一步应使用独立人工标记的自然连续摄像头视频，包含老人、不同视角、遮挡及日常干扰，然后验证真实前端的关键点误差和完整周期性能。
