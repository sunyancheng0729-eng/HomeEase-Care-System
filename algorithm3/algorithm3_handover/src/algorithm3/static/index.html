算法 3 演示:语音交互与声音监测

全部在本机运行。音频只在内存中处理,不保存、不上传;这个页面只是把算法的几个调用点出来给你们看。

正在连接…

1. 声音事件监测

一段录音经过前端(两个门限)、YAMNet 嵌入和逻辑回归,得到 HELP / IMPACT / ABNORMAL / DAILY / UNKNOWN 标签。标签只是提示,不会报警或取消。

2. 回复识别("请问你怎么啦")

语音识别(Whisper tiny)加回复规则 v2,得到 HELP / REASSURANCE / OTHER / UNCERTAIN。没有登记声纹时,"我没事"只凭文字和识别置信度判断。

3. 喊救命检测

模拟持续监听:语音门限切出说话片段,只有 0.3 到 6 秒、识别置信度够、是一句明确的求救话才报警,30 秒内不重复。

4. 报警决策与通道标签

传感器候选加上语音询问的结果,决定事件是否升级,并按固定 10 秒窗口给出 single / dual / triple 通道标签。这里是纯规则,不需要模型。
